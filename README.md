# cumple-isa

Un recorrido por seis años juntos, foto a foto, para el cumpleaños de Isa.

Es una página estática: abre `index.html` en el navegador o publícala con GitHub Pages
(Settings → Pages → rama `master`, carpeta raíz).

Para cambiar textos, edita el arreglo `capitulos` al inicio de `script.js`.
